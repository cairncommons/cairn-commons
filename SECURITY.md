# Security policy

Please report vulnerabilities privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for a vulnerability.

In scope: the local MCP (`scripts/cairn-mcp.ts`, `lib/mcp/`), how it stores or sends credentials, the instructions in the skills, and the schemas. Problems with the cairncommons.dev service itself can be reported the same way.

Never include real credentials or tokens in a report.
